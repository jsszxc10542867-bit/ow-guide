# 오버워치 2026 Phase 3 - 랭크별 맞춤 전략 & 진급 사이클
**기준: 2026년 9월 (현재 메타)**

## 🏆 7가지 랭크와 특징

```
경쟁전 티어 (2026, 낮은 순):
브론즈 → 실버 → 골드 → 플래티넘 → 에메랄드(시즌 4 신설) → 다이아몬드 → 마스터 → 그랜드마스터 → 챔피언

- 각 티어는 5 → 1 디비전으로 나뉩니다 (5가 가장 낮음).
- 아래에 나오는 티어 구분은 "플레이 성향"을 설명하기 위한 것이며, 승급에 필요한 정확한 점수는 인게임에서만 확인할 수 있습니다.
```

## 🥉 BRONZE - "기초 학습 단계"

### 특징
```
플레이어 유형:
- 게임 처음 시작한 사람
- 기본 개념 이해 부족
- 포지셔닝 매우 나쁨
- 팀 협력 거의 없음

게임의 모습:
- 혼자 싸우다 죽음 (자주)
- 탱크 없이 딜러 먼저 싸움
- 힐러가 앞에 있음
- "팀이 뭐?" 상태

특징 요약: "무질서"
```

### Bronze에서의 전략

#### 1. "한 캐릭터만 하기"
```
목표: 게임 방식 이해하기

방법:
□ 첫 50게임 동안 같은 캐릭터만 선택
□ 추천: 우양 (힐러) 또는 윈스턴 (탱크)
□ "이 캐릭터가 뭐 하는 캐릭터인가" 깊이 이해

효과:
- 캐릭터 기술에 집중 가능
- "어? 내가 뭐를 해야 하지" 혼란 없음
- 손 감각 형성 (손가락 근육 기억)

금지:
❌ 여러 캐릭터 동시 학습
❌ "이 캐릭터 재미없다" → 바꾸기
✅ "지루해도 이 캐릭터만"
```

#### 2. "탱크 뒤에만 있기"
```
목표: 포지셔닝 기초 습득

규칙:
□ 항상 탱크를 봄 (탱크가 최전선)
□ 탱크보다 앞에 나가지 말 것 (절대)
□ 탱크와 거리 3-5미터 (가깝지도 멀지도)

결과:
- 혼자 죽는 일 90% 감소
- "탱크가 벽이 되는군" 경험
- 팀 게임의 기초 이해

체크 (매 게임):
□ "내가 탱크보다 앞으로 나갔나?"
□ "탱크가 지금 몇 미터?"
□ "내 생명력이 위험해지지 않았나?"
```

#### 3. "팀 신호 따라가기"
```
목표: 팀 의존성 이해

방법:
□ 채팅에서 "따라해!" 같은 신호 따르기
□ 혼자 판단하지 말 것
□ "우리가 가야 하는 방향" 확인하고 따라가기

예시:
팀: "우측 가자"
❌ 틀린 것: "아니, 좌측이 나을 것 같은데?"
✅ 맞는 것: "좋아, 우측 간다" → 즉시 따라가기

효과:
- "팀 게임" 경험
- 혼자 판단하느라 낭비하는 시간 제거
- "팀을 믿음" 경험

결과:
팀과 함께 → 자주 이김
혼자 판단 → 자주 짐
= "따라가는 게 이기는 거다" 깨달음
```

#### 4. "킬 수 무시하기"
```
Bronze 함정:
"나 이번에 킬 5개 했어!"
→ 게임은 졌음
→ "내 킬이 중요한 게 아니구나" 깨달음

올바른 사고:
"우리 팀이 이겼어!"
→ 내 킬은 2개였음
→ "팀 승리가 최우선" 이해

행동:
□ 게임 후 점수 안 봄 (스코어 무시)
□ "이겼나? 졌나?" 만 확인
□ "왜 이겼을까?" 생각하기
```

#### 5. "완벽함은 나중에"
```
Bronze 초급자의 실수:
"포지셔닝이 정확해야 하고,
스킬 타이밍이 정확해야 하고,
팀 신호도 들어야 하고..."
→ 너무 많은 것을 동시에 생각
→ 아무것도 못함

올바른 생각:
"지금은 그냥 살기만 하자"
□ 포지셔닝: 탱크 뒤에만
□ 스킬: 대충 써도 됨
□ 팀: 신호만 따라가기

= 완벽함 X, 기초 O
```

### Bronze 체크리스트
```
□ 한 캐릭터 50게임 달성?
□ "탱크 뒤" 위치 습득?
□ 팀 신호 이해했나?
□ 1게임에서 혼자 안 싸우나?
□ 게임 이해 50% 정도?

모두 체크 → Silver 준비 완료!
```

## 🥈 SILVER - "기초 마스터 단계"

### 특징
```
플레이어 유형:
- Bronze 기초 습득함
- 포지셔닝 개념 이해 시작
- "왜 이겼을까" 생각하기 시작
- 팀 게임 중요성 인식

게임의 모습:
- 자기 역할은 하는 중
- 가끔 좋은 포지션
- 팀 신호 대충 따름
- "그래도 헷갈리네"

특징 요약: "학습 중"
```

### Silver에서의 전략

#### 1. "포지셔닝 집중"
```
목표: 위치가 모든 것을 결정하는 것 깨닫기

지난 단계: 탱크 뒤에만
이 단계: "탱크 뒤의 어디?"

분석:
□ 왜 내가 죽었을까? → 위치 때문이었나?
□ 왜 이겼을까? → 좋은 위치에 있었나?
□ 실수의 80% = 포지셔닝 실수

행동:
매 게임 후 "가장 좋은 순간의 위치"와
"가장 나쁜 순간의 위치" 비교
→ 차이 분석
→ 다음 게임에 반영
```

#### 2. "두 번째 캐릭터 시작"
```
목표: 역할 이해 (같은 역할, 다른 캐릭터)

방법:
기존: 우양 (50게임)
추가: 바티스트 (새로운 지원 캐릭터)

장점:
□ "지원 역할의 다양성" 이해
□ "이 상황에는 이 캐릭터" 판단 시작
□ 팀이 "우리 힐러 뭐야?" 안 물어봐도 됨

게임 수:
Silver 100-150게임 동안
우양 60게임 + 바티스트 40게임

결과:
"같은 역할도 다양하구나" 깨달음
```

#### 3. "팀 전술 이해"
```
목표: "왜 이겼나" 답하기

이전: 게임을 했다
현재: 게임을 분석한다

질문:
□ 우리 팀 구성이 뭐였나?
□ 그 구성의 강점은?
□ 어디서 이겼나?
□ 상대팀이 뭔가 못 했나?

예시:
"아, 우리 팀이 Dive 조합이었구나"
"그래서 빠르게 끝낼 수 있었구나"
"다음에 상대팀이 느린 팀이면 Dive 써야겠다"
```

#### 4. "통신 시작"
```
목표: 말로 팀과 소통하기

이전: "따라가" (신호 받기만)
현재: "우측 가자!" (신호 주기)

방법:
음성채팅 켜기 (꼭!)
매 게임:
□ 인사 (시작 전)
□ 상황 보고 (진행 중)
□ "함께 가자" (공격 전)
□ "좋은 경기" (끝난 후)

효과:
팀 분위기 +50%
→ 자동으로 게임 이김
```

#### 5. "카운터픽 인식"
```
목표: "상대에 따라 다르다" 깨닫기

학습:
상대팀이 윈스턴? → 원거리 딜러 선택
상대팀이 거리팀? → Dive 조합 선택
상대팀이 힐러 없음? → 계속 진입

방법:
□ 상대팀 구성 확인 (게임 시작 시)
□ "어? 저건 뭔 조합인가?"
□ 팀에 물어보기 (음성)
□ "그럼 우리는 이거?"

결과:
"같은 전술도 상대에 따라 다르다" 이해
```

### Silver 체크리스트
```
□ 두 번째 캐릭터 40게임 이상?
□ 포지셔닝으로 1게임 이상 차이 느껴봤나?
□ 음성채팅 사용하기 시작했나?
□ "왜 이겼을까" 분석 습관?
□ 팀 전술 3가지 이상 경험?

모두 체크 → Gold 준비 완료!
```

## 🟡 GOLD - "중급 단계"

### 특징
```
플레이어 유형:
- Silver 마스터함
- 의식적 플레이 시작
- "뭔가 모르는 게 있다" 느낌
- 팀과 자주 이김

게임의 모습:
- 포지셔닝 대부분 좋음
- 팀 신호 잘 따름
- 가끔 개인 실수 (타이밍, 스킬)
- "왜 졌을까?" 이해 안 됨

특징 요약: "자신감 생김"
```

### Gold에서의 전략

#### 1. "개인 기술 연습"
```
목표: 포지셔닝은 좋은데 왜 자꾸 죽지?

원인 분석:
□ 스킬 타이밍 (너무 일찍/늦게)
□ 궁극기 관리 (낭비)
□ 반응속도 (상대가 너무 빠름)

연습:
주 1-2회: "개인 기술만" 연습 게임
□ 팀은 상관없이 내 역할만
□ "우리 이기는 건 운이고, 나는 기술 연습"
□ 점수 안 봄 (점수 = 팀 결과)

효과:
포지셔닝 95% 
+ 기술 70%
= 총 90% 이상 실력
```

#### 2. "역할별 메인 캐릭터 확정"
```
목표: "내가 잘하는 캐릭터" 찾기

방법:
□ 탱크: 1명 (예: 윈스턴)
□ 딜러: 1명 (예: 시에라)
□ 지원: 1명 (예: 우양)
= 총 3명

각 게임:
"팀이 부족한 역할" 채우기
예: 탱크 부족? → 윈스턴
예: 딜러 부족? → 시에라

이점:
□ "이 캐릭터는 완벽" 상태
□ 팀이 "그 선수, 저 캐릭터 잘해" 인식
□ 신뢰도 상승
```

#### 3. "멘탈 강화"
```
목표: 연속 패배 극복하기

상황:
연속 패배 (3연패)
→ "그 팀과는 질려 있다"
→ 포기감
→ 계속 짐

해결책:
Phase 3: 멘탈 마스터리 활용
□ "패배도 배움" 수용
□ 팀 탓하지 말기
□ "뭐가 안 됐을까" 분석

결과:
심리적 회복 → 다시 이김
```

#### 4. "팀 신뢰도 구축"
```
목표: 같은 팀원과 계속 플레이

이점:
같은 팀원 × 10게임
→ "이 친구는 이렇게 할 거야" 예상 가능
→ 커뮤니케이션 없이도 작동
→ 게임 수월해짐

방법:
□ 좋은 플레이어 팀원 기억
□ "다음엔 이 팀원과 해보자" 찾기
□ 팀 리더 될 기세로 이끌기

효과:
개인 기술 + 팀 신뢰
= Gold 마스터
```

#### 5. "랭크 진급의 벽 인식"
```
Gold의 함정:
"나 Platinum도 갈 수 있겠는데?"
→ 자신감만 가득
→ 준비 부족
→ Platinum 올라갔다 내려옴

올바른 태도:
"Gold에서 완벽해지자"
□ 포지셔닝: 99%
□ 기술: 80%
□ 팀 신뢰: 높음
□ 멘탈: 안정적

= Platinum 올라갔을 때도 떨어지지 않음
```

### Gold 체크리스트
```
□ 세 역할 대표 캐릭터 각 30게임 이상?
□ 포지셔닝 실수 거의 안 하나?
□ 개인 기술 70% 이상인가?
□ 연속 패배 (3-4)에도 침착한가?
□ 같은 팀원과 자주 해봤나?

모두 체크 → Platinum 준비 완료!
```

## 💎 PLATINUM - "상급 단계"

### 특징
```
플레이어 유형:
- "꽤 잘하는" 플레이어
- 실수가 줄어듦
- "뭔가 더 있을 것" 같은 느낌
- 이기고도 만족 안 함

게임의 모습:
- 포지셔닝: 거의 완벽
- 기술: 85%
- 팀: 자주 이김
- "왜 못 올라갈까?" 의문

특징 요약: "절정기"
```

### Platinum에서의 전략

#### 1. "상대팀 읽기"
```
목표: "상대팀 약점" 찾고 공략하기

방법:
게임 시작 1분:
□ 상대팀 구성 분석
□ "상대팀 강점은?"
□ "상대팀 약점은?"
□ "우리가 공략할 부분은?"

예시:
상대팀: 윈스턴 + 트레이서 (Dive)
분석: "우회에 약하다"
공략: "우리는 저격으로 트레이서 마크"

결과:
"맞춤형 방어" → 자동으로 이김
```

#### 2. "판단 속도 극대화"
```
목표: 매 순간 최적의 판단

현재: "어? 뭐 할까?" (생각함)
목표: "아, 이건 이거다!" (본능)

방법:
상황별 의사결정 연습
□ 5v3? → "강진입"
□ 3v5? → "후퇴"
□ 1v1? → "혼자 싸우지 말기"

효과:
생각 0.5초 단축
= 반응속도 두배
= 자동으로 이김
```

#### 3. "팀 리더십"
```
목표: 팀을 이끌기

행동:
게임 시작:
□ "안녕하세요!" (긍정적 분위기)
□ "이번엔 이 전술로 할까요?" (제안)
□ "각자 잘하시는 거 하세요" (격려)

게임 중:
□ "좋은 플레이!"
□ "함께 가자"
□ "괜찮아, 다음이 있어"

게임 후:
□ "재밌는 경기였어요"
□ 지면 "좋은 경험이었어요"

효과:
팀 분위기 +100%
→ 팀의 실력이 120% 나옴
```

#### 4. "상황별 변칙 플레이"
```
목표: "같은 전술도 다르게" 해보기

예시:
정상: Dive 조합 (빠르게 들어가기)
변칙: Dive 조합 (느리게 포지션 잡고 기습)

효과:
상대팀이 "어? 뭐지?" 생각하는 순간
우리가 공격
→ 준비 안 된 상태에서 당함
→ 자동 승리
```

#### 5. "Platinum 정체 극복"
```
Platinum의 벽:
"이제 뭘 해야 할까?"
→ "내가 할 수 있는 게 다 했는데?"
→ 진급 안 됨

해결책:
"내 약점 찾기"
□ 멘탈? (피로로 집중 못함)
□ 커뮤니케이션? (팀과 말 안 됨)
□ 기술? (특정 상황에서 약함)
□ 판단? (틀린 판단이 많음)

1개 약점만 집중 개선
→ 자동으로 Diamond 올라감
```

## 💚 EMERALD - "다이아 문턱 단계" (2026 시즌 4 신설)

### 특징
```
위치: 플래티넘과 다이아몬드 사이 (상위 약 35% ~ 15%)
생긴 이유: 플래티넘 상위 ~ 다이아 하위에 실력 편차가 너무 커서
          "다이아 문턱"을 따로 떼어 낸 구간

플레이어 유형:
- 개인 기량은 다이아와 거의 같음
- 하지만 "판단이 늦거나" "혼자 잘함"
- 이기면 다이아 같고, 지면 플래티넘 같음
- 승률이 50% 근처에서 오래 머묾

게임의 모습:
- 포지셔닝: 좋음, 하지만 한타 중간에 흐트러짐
- 기술: 90%
- 팀: 절반은 콜을 함, 절반은 안 함
- "다이아 가는 사람"과 "플래티넘 내려가는 사람"이 섞인 방

특징 요약: "실력은 됐고, 일관성이 없다"
```

### Emerald에서의 전략

#### 1. "한 판 안에서 일관성 유지"
```
에메랄드의 진짜 문제:
첫 한타는 다이아처럼 → 세 번째 한타는 골드처럼

원인: 한타 결과에 따라 플레이가 바뀜
- 이기면 → 과감해짐 → 무리 → 죽음
- 지면 → 소극적 → 팀과 따로 → 죽음

해결:
□ 한타 결과와 상관없이 "같은 규칙"으로 플레이
□ 이겼어도 리그룹 (추격 금지)
□ 졌어도 같은 위치에서 재정비 (숨지 않기)
□ 죽었을 때 복기: "규칙을 어겼나?"가 첫 질문

효과: 승률 50% → 55% (이 5%가 다이아를 만듦)
```

#### 2. "다이아 문턱 = 궁 트래킹"
```
플래티넘과 다이아의 가장 큰 차이:
"상대 궁이 몇 개 있는지 아느냐"

에메랄드에서 해야 할 것:
□ 한타 시작 전 "상대 궁 몇 개?" 스스로 물어보기
□ 최소 2개(상대 탱커 궁 + 가장 위험한 딜러 궁)는 기억
□ "상대 그라비 있음" 한 마디 콜

방법:
게임 시작 → 첫 한타까지는 아무도 궁 없음
첫 한타 후 → "누가 궁을 썼고 누가 안 썼나" 기억
= 안 쓴 사람은 다음 한타에 궁이 있음

효과:
"어? 궁 있었어?"로 지는 한타가 사라짐
→ 다이아 문턱을 넘음
```

#### 3. "내 영웅 풀을 좁히기"
```
에메랄드 흔한 실수: "다 할 줄 알아야 다이아 간다"
현실: 다이아 이하는 주력 영웅 2개면 충분

해야 할 것:
□ 역할당 주력 1개 + 카운터용 1개 = 2개
□ 카운터당해도 "플레이 방식"을 먼저 바꾸고, 그래도 안 되면 교체
□ 새 영웅은 빠른 대전에서만

효과:
같은 영웅 100판 = 판단이 본능이 됨
= 한타 중 생각 시간이 0.5초 줄어듦
= 다이아
```

#### 4. "지는 판 30초 안에 인정하기"
```
에메랄드에서 티어 갉아먹는 습관:
"이미 진 판"에 20분을 쓰고 멘탈이 무너져 다음 판까지 짐

방법:
□ 한타 3연패 → "이 판은 배우는 판"으로 전환
□ 배우는 판에서는 한 가지만 연습 (예: 궁 트래킹만)
□ 게임 끝나면 결과 대신 "연습한 것"만 기록

효과:
연패가 2판에서 끝남
= 하루 승률이 안정
= 에메랄드 → 다이아
```

### Emerald 체크리스트
```
□ 이긴 한타 뒤에도 리그룹하나? (추격 안 함)
□ 한타 전에 상대 궁 2개 이상 기억하나?
□ 주력 영웅 2개로 90% 이상 플레이하나?
□ 3연패 후 플레이가 바뀌지 않나?
□ 콜을 한 판에 5번 이상 하나? ("궁 있음", "리그룹", "들어가자")

모두 체크 → Diamond 준비 완료!
```

## 💠 DIAMOND - "상위권 진입 단계"

### 특징
```

특징 요약: "거의 완벽"
```

### Diamond에서의 전략

#### 1. "매크로 플레이"
```
목표: "개별 기술"에서 "전체 맵" 보기

현재: "여기서 이 상황 어떻게 할까?"
목표: "전체 맵에서 어디가 중요할까?"

예시:
"우리 우측이 강하니까
우측에서 이기는 것에 집중하자"

"상대팀 저격수가 강하니까
저격수를 마크하는 데 자원 집중"
```

#### 2. "픽 순서 전략"
```
목표: 첫 픽이 게임을 결정한다

이해:
상대팀 첫 픽이 윈스턴?
→ "아, 우리는 저격이 필요해"
→ 즉시 위도우메이커 선택

결과:
게임 시작 전부터
"이미 반은 이겼다" 느낌
```

#### 3. "1분 1초의 중요성"
```
목표: 매 순간이 게임을 결정한다

예시:
"지금 4v4지만, 우리 궁극기 1개 더 있어"
= "지금 우리가 이긴다"

다시:
"지금 5v5지만, 상대 궁극기 다 찬 상태"
= "지금 우리가 져야 한다"

= 실시간 상황 정밀 판단
```

### Diamond 이후는?

Diamond부터는:
- 개인 기술 한계 도달
- 팀 게임 + 정신력이 결정
- 프로 수준에서의 경쟁
- 멘탈이 가장 중요
