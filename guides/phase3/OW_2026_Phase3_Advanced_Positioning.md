## 🗺️ 포지셔닝이 승리를 결정한다

### 현실: "기술보다 위치가 50% 이상이다"
```
프로 경기 분석:

같은 기술의 두 팀:
팀 A: 포지셔닝 완벽
팀 B: 포지셔닝 형편없음

결과: 팀 A 승률 80% 이상

이유:
1. 포지셔닝 좋음 = 정보 많음
2. 정보 많음 = 판단 빠름
3. 판단 빠름 = 반응 빠름
4. 반응 빠름 = 승리

= 포지셔닝 개선 → 실력 급상승
```

## 🎯 맵 1: 도라도 (Dorado) - 화물 호위

### 맵 구조 파악
```
전체 구조:
├─ 1구간: 시장 (골목 많음, 사이드가 열림)
├─ 2구간: 다리 (다리 위 건물이 핵심 고지)
├─ 3구간: 발전소 (실내, 2층 통로)

고지: 시장 건물 2층 · 다리 위 건물 · 발전소 2층 통로
초크: 시장 입구 · 다리 · 발전소 문
힐팩: 시장 안 큰 팩 · 다리 아래 큰 팩 · 발전소 안 작은 팩
```

### 공격팀 포지셔닝 (Attacker)
```
1구간 (시장):
- 카트가 정면 시선을 잡는 동안 딜러 하나가 뒷골목(사이드)으로 돌아 2층을 잡습니다.
- 탱커: 카트 옆. 힐러: 카트 뒤 코너.
- 금지: 시장 골목에서 혼자 돌아다니기 → 플랭커에게 잘립니다.

2구간 (다리):
- 다리 위 건물을 먼저 비워야 카트가 지나갑니다. 위에서 내려다보는 수비를 정면으로 밀지 말고, 다리 아래 팩 쪽으로 돌아 건물 뒤에서 올라가세요.

3구간 (발전소):
- 발전소 문은 초크입니다. 옆 계단(사이드)으로 딜러가 먼저 2층에 올라가 시야를 뺏은 뒤 카트를 밉니다.
```

### 수비팀 포지셔닝 (Defender)
```
- 1구간: 시장 건물 2층에서 카트를 내려다봅니다. 골목으로 오는 플랭커를 힐러 옆에서 잡으세요.
- 2구간: 다리 위 건물 = 수비 핵심. 카트가 다리를 지나면 발전소 2층으로 물러납니다.
- 3구간: 2층 통로에서 문(초크)을 내려다보며 수비. 사이드 계단을 한 명이 지켜야 뒤가 안 뚫립니다.
```

## 🎯 맵 2: 리장 타워 (Lijiang Tower) - 쟁탈

### 맵 구조
```
3개 거점 (야시장 / 정원 / 타워)

고지: 야시장 거점 뒤 2층 발코니 · 정원 정자 지붕과 2층 통로 · 타워 거점 옆 창문 통로
초크: 야시장 거점 정면 문 · 정원 다리 · 타워 거점 진입 문
힐팩: 야시장 거점 옆 작은 팩 · 정원 정자 뒤 큰 팩 · 타워 통로 큰 팩

특징:
- 타워는 거점 창문 밖이 낭떠러지 → 넉백(루시우·둠피스트·로드호그)이 강합니다.
- 정원은 정자 지붕 위가 핵심. 위에서 거점을 내려다보는 팀이 유리합니다.
```

### 쟁탈 전술: "고지점 확보가 전부"
```
초반 (거점 열리기 전):
- 5명이 같이 도착합니다. 먼저 간 사람이 잘못한 것입니다.
- 딜러: 정자 지붕 / 2층 발코니를 먼저 잡습니다.
- 탱커: 거점 안 벽 옆 (타워는 창문 반대편).
- 힐러: 거점 뒤 기둥 뒤, 낭떠러지 반대편.

거점 점령 후:
- 99% 대 99%가 되면 마지막 한타가 승부입니다. 궁을 세어 두세요.
- 지는 한타면 거점 위에서 죽지 말고 빠져서 5명으로 다시 옵니다.

금지:
- 타워 거점에서 창문 쪽에 서 있기 → 넉백 한 번에 떨어집니다.
```

## 🎯 맵 3: 왕의 길 (King's Row) - 혼합(점령 후 호위)

### 맵 구조
```
1거점: 광장 (호텔 2층·발코니가 수비 핵심)
2구간: 도로 (도로 옆 건물 2층, 지하철 입구 앞 좁은 길)
3구간: 공장 (진입 문이 초크, 안쪽 2층 통로)

사이드: 1거점 왼쪽 호텔 안 계단 → 2층 발코니 · 2구간 오른쪽 상점 골목 · 3구간 공장 왼쪽 옆문
힐팩: 호텔 안 큰 팩 · 지하철 입구 안 큰 팩 · 공장 안 작은 팩 2개
```

### 공격팀 포지셔닝
```
1거점:
- 정문 아치로 5명이 걸어 들어가지 않습니다 (시그마·바스티온에게 녹는 가장 흔한 패배).
- 호텔 안으로 돌아 2층 발코니를 먼저 잡으면 거점이 열립니다.
- 탱커: 정문 안쪽 기둥 옆. 딜러: 호텔 2층·발코니. 힐러: 호텔 1층 안쪽 코너.

2구간 (카트):
- 카트 옆(탱커)·카트 뒤 코너(힐러). 딜러는 도로 옆 건물 2층에서 아래를 내려다봅니다.
- 지하철 입구 앞 좁은 길은 초크 → 상점 골목(사이드)으로 한 명이 돌아 시선을 나눕니다.

3구간 (공장):
- 공장 진입 문 정면 돌파 금지. 왼쪽 옆문으로 2층 통로를 먼저 잡습니다.
```

### 수비팀 포지셔닝
```
- 1거점: 호텔 2층에서 정문을 내려다보며 수비. 발코니를 뺏기면 거점 뒤로 물러나 다시 잡습니다.
- 2구간: 도로 옆 건물 2층 → 지하철 입구 앞 좁은 길에서 시간을 법니다.
- 3구간: 공장 안 2층 통로에서 문을 내려다봅니다. 옆문을 한 명이 지켜야 합니다.
```

(실제 오버헤드 지도 위 마커로 보려면 사이트의 "실전 맵" 탭을 여세요.)

## 💡 포지셔닝 원칙 5가지

### 원칙 1: "항상 뒤돌아보기"
```
상황: 정면으로 싸우는 중

문제:
- 옆에서 공격당함 (안 봤음)
- 뒤에서 공격당함 (완전 놀람)
→ 즉사

해결:
"2초마다 뒤돌아보기"
□ 1초: 정면 공격
□ 1초: 좌측 확인
□ 1초: 정면 공격
□ 1초: 우측 확인
□ 1초: 정면 공격
□ 1초: 뒤 확인

효과:
- 주변 공격 감시 가능
- "아, 거기서 온다" 예상 가능
- 반응 시간 확보
```

### 원칙 2: "엄폐물 뒤에 서기"
```
상황: 적과 거리 유지 중

❌ 포지션 (나쁜 예):
- 완전히 노출 (엄폐물 없음)
- 결과: 모든 공격 맞음 → 죽음

✅ 포지션 (좋은 예):
- 엄폐물 뒤에 반쯤 숨음
- 공격할 때만 나옴
- 결과: 피해 50% 감소

엄폐물 사용법:
□ 뒤에만 섬 (옆에 나오지 말기)
□ 많이 움직이지 말기 (위치 이미 알려짐)
□ "인-아웃" (숨었다 나왔다 반복)
```

### 원칙 3: "높은 곳이 유리하다"
```
이유: "위 > 아래"
- 정보 많음 (더 많이 봄)
- 회피 쉬움 (점프해서 내려감)
- 슈팅 각도 유리 (아래를 봄)

하지만:
- 도망칠 곳 적음
- "높은 곳에 있네" = 타겟
- 혼자 올라가면 위험

포지셔닝 원칙:
□ 고지점에 올라가기 (정보 수집)
□ 하지만 팀과 가까워야 함
□ 좌회전 경로 미리 확인 (도망칠 준비)
□ 위험하면 즉시 내려오기
```

### 원칙 4: "탱크와 거리 유지"
```
기본 거리:
- 탱크: 최전선
- 딜러: 탱크로부터 3-5미터 뒤
- 힐러: 딜러로부터 3-5미터 뒤

효과:
□ 딜러 보호됨 (탱크가 앞에서 피해 흡수)
□ 힐러 안전 (적이 도달하기 전에 도망)
□ 효율적 (모두가 제 역할 수행)

❌ 거리 틀린 경우:
- 너무 앞: 보호 못 받음 → 죽음
- 너무 뒤: 탱크 혼자 싸움 → 패배
```

### 원칙 5: "상황에 따라 움직이기"
```
상황 1: 우리 우위 (5v3)
→ 적극적 포지션 (앞으로!)
→ 적을 쫓기 (역할 교체)

상황 2: 우리 열세 (3v5)
→ 방어적 포지션 (뒤로!)
→ 적을 기다리기 (준비 완료)

상황 3: 동등 (5v5)
→ 중립 포지션 (적절)
→ 신호 대기 (팀이 결정)

포지셔닝은 고정 X, 유동적이어야 함
→ "지금 상황" 파악
→ "적절한 위치" 선택
→ "결과" 관찰
```

## 🎮 실전 연습: 포지셔닝 개선 프로그램

### 주 1회: "포지셔닝만 집중"
```
게임 설정:
- 맵 지정 (예: 왕의 길)
- 전술 지정 (예: Dive)
- 목표: 포지셔닝 연습 (킬 수 X)

게임 중:
□ 매 10초마다 "지금 내 포지션 맞나?" 체크
□ 틀렸으면 즉시 수정
□ 맞으면 유지

게임 후:
□ "언제가 가장 좋은 포지션이었나?"
□ "언제가 가장 나쁜 포지션이었나?"
□ "다음엔 뭘 고칠까?"
```

### 주 2회: "맵별 포지셔닝"
```
월요일: 도라도 포지셔닝 연습 (5게임)
수요일: 리장 타워 포지셔닝 연습 (5게임)
금요일: 킹스로우 포지셔닝 연습 (5게임)

1주일 = 각 맵 5게임씩 = 깊이 있는 학습
```

### 주 1회: "높은 곳 감각 익히기"
```
목표: 고지점에서 거리감 배우기

연습:
1. 높은 포지션에서만 경기 (저격, 위도우메이커 등)
2. 10게임 연속 고지점 점령
3. "여기서는 안전하다" 감각 체득
4. "여기서는 위험하다" 감각 체득

효과:
- 모든 캐릭터 사용할 때 "높이 감각" 생김
- 고지점 확보 전술 이해
- "왜 저격수가 강한가" 깨달음
```

## 📊 포지셔닝 체크리스트 (매 게임)

### 게임 중 (5분마다)
```
□ 내 포지션이 팀과 함께인가?
□ 탱크가 보이는가?
□ 힐러가 내게 빔을 연결하고 있는가?
□ 뒤에 적이 있을 수도 있다 (경각심)
□ 지금 내 위치가 상황에 맞는가?

만약 "아니오" 답이 하나라도:
→ 즉시 포지션 수정!
```

### 게임 후
```
□ 가장 잘한 포지션 순간은?
□ 가장 못한 포지션 순간은?
□ 패배의 이유 = 포지션? 기술? 팀?
□ 다음엔 뭘 고칠까?

점수 (1-10):
□ 포지셔닝 개선도: __점
→ 5점 미만: 다시 연습
→ 7점 이상: 다음 맵으로 진행
```
