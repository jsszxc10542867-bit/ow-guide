## 🗺️ 포지셔닝이 승리를 결정한다

### 현실: "기술보다 위치가 50% 이상이다"
```
프로 경기 분석:

같은 기술의 두 팀:
팀 A: 포지셔닝 완벽
팀 B: 포지셔닝 형편없음

결과: 팀 A 승률 80% 이상

이유:
1. 포지셔닝 좋음 = 정보 많음
2. 정보 많음 = 판단 빠름
3. 판단 빠름 = 반응 빠름
4. 반응 빠름 = 승리

= 포지셔닝 개선 → 실력 급상승
```

## 🎯 맵 1: 아이작산 (Isaac Mountain) - Escort

### 맵 구조 파악
```
전체 구조:
├─ 스타팅 포인트 (Attacker Spawn)
├─ 1구간: 실내 (좁음)
├─ 2구간: 실외 (넓음)
├─ 3구간: 최종 지점 (실내 + 높은 곳)

특징:
- 좁은 통로 많음
- 높이 차이 큼 (3단계)
- 엄폐물 풍부
- Defender 유리한 맵
```

### 공격팀 포지셔닝 (Attacker)

#### 초반 진입 (0-2분)
```
기본 전술: Dive Composition 사용

포지셔닝 맵:
```
     [높은 곳]
         ↑ 위도우메이커 (저격, 높은 곳에서)
    [실내 좁은 길]
         ↑ 윈스턴 (배리어)
      ↙  ↓  ↘
    트레이서 정크랫 겐지
     (좌)  (중)   (우)

[뒤쪽 안전한 곳]
     ↓
  우양 + 루시우 (힐러들)
```

**각 포지션 설명:**

```
1. 윈스턴 (탱크)
   위치: 정면 중앙 통로 입구
   역할: 배리어로 진입로 확보
   주의: 좌우 측면 공격 조심
   신호: "진입한다!"

2. 트레이서 (빠른 딜러)
   위치: 좌측 높은 곳 우회 (맵 왼쪽 계단)
   역할: 적 후방 압박, Defender 주의 분산
   주의: 혼자 진입 X, 모두 들어왔을 때
   신호: "좌측에서 들어간다!"

3. 정크랫 (광역 딜러)
   위치: 정면 윈스턴 바로 뒤
   역할: 광역 피해, 좁은 통로 점령
   주의: 아군에게 피해 주지 말기
   신호: 없음 (윈스턴 따라가면 됨)

4. 겐지 (민첩 딜러)
   위치: 우측 높은 곳 우회
   역할: 우측 측면 압박, 순간 피해
   주의: 너무 앞으로 X
   신호: "우측에서 온다!"

5. 힐러 (우양 + 루시우)
   위치: 중앙 뒤쪽, 모든 사람이 보이는 곳
   역할: 지속적 치유, 속도 버프
   주의: 절대 앞에 나오지 말기
   신호: "치유 필요하면 말해줘"
```

#### 전투 중 포지셔닝 (2-5분)
```
전투 1단계: 진입 성공

상황: 윈스턴이 적을 1명 처리했음
현재 5v4 (우리 우위)

포지셔닝:
```
     [높은 곳 - 위도우메이커]
            ↑ 적 한 명이 도망쳤음
     ↑ 계속 저격
    
    [실내 전투지역]
    윈스턴 (체력 70%)
         ↙  ↓  ↘
  트레이서  Junk  겐지
   계속   광역  순간
   압박   피해  피해

[뒤쪽]
  힐러들 (우양 = 윈스턴 계속 치유)
```

**핵심 포지셔닝 원칙:**
- 윈스턴이 최전선 유지 (피해 흡수)
- 딜러들은 윈스턴 뒤에서 (안전)
- 힐러는 계속 윈스턴에 빔 연결 (생존 보장)
- 위도우메이커는 높은 곳 고수 (지원 계속)

전투 2단계: 한 명 더 처리

```
현재: 5v3 (우리 크게 우위)

포지셔닝:
- 윈스턴: 더 진입 (배리어 원칙 유지)
- 딜러: 윈스턴 계속 따라가기
- 힐러: 치유 강화 (이제 손쉬움)

결과: 페이로드 점유 시작
```

#### 최종 지점 (5분+) - 가장 위험한 구간
```
맵 특징: 실내 + 높은 곳 많음
Defender 유리: "우리 맵이야"

우리의 전략: "빠르게 끝내기"

포지셔닝:
```
[위층 - 위도우메이커 위치]
    높은 저격 포지션
    상황: Defender 저격수 대치

[중층 - 페이로드 위치]
    윈스턴 (배리어)
    정크랫 (광역)
    루시우 (속도 증가)

[아래층 - 우회 경로]
    트레이서 + 겐지
    우회로로 Defender 측면 압박

[뒤에서 뒷치기]
    우양 (중요! 생존이 우선)
    모든 사람이 보이는 위치
```

**결정적 순간:**
Defender가 "쇄도" 시도
→ 트레이서 & 겐지가 우회로에서 저격수 처리
→ 위도우메이커 위협 제거
→ 윈스턴이 정면으로 강진입
→ 페이로드 타겟 도달!

### 수비팀 포지셔닝 (Defender)

#### 초반 방어 (0-2분)
```
목표: Attacker 느리게 진입하게 만들기

기본 전술: Poke Composition (거리 유지)

포지셔닝:
```
[최초 방어선 - 1구간 입구]
    오리사 (탱크, 정면 차단)
    역할: 거리 유지, 진입 지연

[양쪽 높은 곳]
    좌: 저격수 (위도우메이커)
    우: 지원 저격 (아나)

[뒤쪽 - 2구간 입구]
    측면 압박용 캐릭터
    (겐지 또는 빠른 딜러)

[최후방]
    힐러 (바티스트 또는 아나)
    위치: 오리사가 봐야 하는 곳
```

**방어의 핵심:**
- 오리사가 첫 번째 엄폐물 차지 (쉽게 밀려나지 않기)
- 저격수들이 높은 곳에서 "견제"
- 측면 공격 준비 (우회 경로 감시)

#### 우회 방지 (매우 중요!)
```
Attacker의 전술: 트레이서 + 겐지 우회
→ 이걸 못하게 하면 우리 승리

Defender의 대처:

좌측 우회로:
└─ Roaming 캐릭터 1명 배치
   (겐지, 트레이서, 메이 등)
   역할: 트레이서 저지
   위치: 우회 경로 중간 지점

우측 우회로:
└─ 유사하게 배치

핵심: "우회 = 죽음"
    → Attacker가 우회 안 함
    → 정면으로만 올 수밖에 없음
    → 우리가 준비된 포지션에서 대기
    → 방어 성공
```

## 🎯 맵 2: 리잔 (Lissan) - Control

### 맵 구조
```
전체: 넓은 광장
특징:
- 중앙에 높은 고지점 (타워)
- 정면 진입, 좌우 우회로
- 개방적 (숨을 곳 적음)
- Attacker 유리 (넓음)
```

### Control 전술: "고지점 확보가 전부"
```
목표: 중앙 타워 점령
문제: Defender도 같은 목표
결과: 고지점에서 격전

우리 Attacker 전술:
"Dive로 빠르게 타워 점령하기"
```

### 초반 공격 (0-3분)
```
포지셔닝 맵:
```
[북쪽 높은 곳]
    위도우메이커 (저격)
    
[중앙 타워 - 최중요]
    윈스턴 (배리어)
    트레이서 (빠른 공격)
    정크랫 (광역)
    
[남쪽 우회로]
    겐지 (빠른 측면 공격)
    
[뒤에 안전한 곳]
    우양 (치유)
```

**시간대별 진입:**

```
0초: 준비 (모두 진입 대기)
신호: "들어간다!"

1초: 윈스턴 점프
→ 배리어 펼침 (중앙 타워)
→ Defender 주의 끌기

1.5초: 트레이서 + 정크랫 즉시 진입
→ 윈스턴 뒤에 숨음
→ 광역 피해 시작

2초: 위도우메이커 저격 시작
→ 우회로 감시 (Defender 저격수)

3초: 겐지 우회
→ Defender 측면 위협

결과: 모든 각도에서 공격
→ Defender 혼란
→ 타워 점령
```

### 타워 점령 후 (3-5분)
```
상황: 우리 점령률 40% (리드 중)

포지셔닝 (계속 유지):
- 윈스턴: 타워 중앙 (방어)
- 딜러들: 윈스턴 주변 (범위 공격)
- 힐러: 윈스턴 치유 강화

위험: Defender 반격

Defender가 "쇄도" 시도
→ 우리는 이미 "방어 진지" 구축
→ 높은 곳에서 저격
→ Attacker 역전 → 포지션 유지

## 💡 포지셔닝 원칙 5가지

### 원칙 1: "항상 뒤돌아보기"
```
상황: 정면으로 싸우는 중

문제:
- 옆에서 공격당함 (안 봤음)
- 뒤에서 공격당함 (완전 놀람)
→ 즉사

해결:
"2초마다 뒤돌아보기"
□ 1초: 정면 공격
□ 1초: 좌측 확인
□ 1초: 정면 공격
□ 1초: 우측 확인
□ 1초: 정면 공격
□ 1초: 뒤 확인

효과:
- 주변 공격 감시 가능
- "아, 거기서 온다" 예상 가능
- 반응 시간 확보
```

### 원칙 2: "엄폐물 뒤에 서기"
```
상황: 적과 거리 유지 중

❌ 포지션 (나쁜 예):
- 완전히 노출 (엄폐물 없음)
- 결과: 모든 공격 맞음 → 죽음

✅ 포지션 (좋은 예):
- 엄폐물 뒤에 반쯤 숨음
- 공격할 때만 나옴
- 결과: 피해 50% 감소

엄폐물 사용법:
□ 뒤에만 섬 (옆에 나오지 말기)
□ 많이 움직이지 말기 (위치 이미 알려짐)
□ "인-아웃" (숨었다 나왔다 반복)
```

### 원칙 3: "높은 곳이 유리하다"
```
이유: "위 > 아래"
- 정보 많음 (더 많이 봄)
- 회피 쉬움 (점프해서 내려감)
- 슈팅 각도 유리 (아래를 봄)

하지만:
- 도망칠 곳 적음
- "높은 곳에 있네" = 타겟
- 혼자 올라가면 위험

포지셔닝 원칙:
□ 고지점에 올라가기 (정보 수집)
□ 하지만 팀과 가까워야 함
□ 좌회전 경로 미리 확인 (도망칠 준비)
□ 위험하면 즉시 내려오기
```

### 원칙 4: "탱크와 거리 유지"
```
기본 거리:
- 탱크: 최전선
- 딜러: 탱크로부터 3-5미터 뒤
- 힐러: 딜러로부터 3-5미터 뒤

효과:
□ 딜러 보호됨 (탱크가 앞에서 피해 흡수)
□ 힐러 안전 (적이 도달하기 전에 도망)
□ 효율적 (모두가 제 역할 수행)

❌ 거리 틀린 경우:
- 너무 앞: 보호 못 받음 → 죽음
- 너무 뒤: 탱크 혼자 싸움 → 패배
```

### 원칙 5: "상황에 따라 움직이기"
```
상황 1: 우리 우위 (5v3)
→ 적극적 포지션 (앞으로!)
→ 적을 쫓기 (역할 교체)

상황 2: 우리 열세 (3v5)
→ 방어적 포지션 (뒤로!)
→ 적을 기다리기 (준비 완료)

상황 3: 동등 (5v5)
→ 중립 포지션 (적절)
→ 신호 대기 (팀이 결정)

포지셔닝은 고정 X, 유동적이어야 함
→ "지금 상황" 파악
→ "적절한 위치" 선택
→ "결과" 관찰
```

## 🎮 실전 연습: 포지셔닝 개선 프로그램

### 주 1회: "포지셔닝만 집중"
```
게임 설정:
- 맵 지정 (예: 아이작산)
- 전술 지정 (예: Dive)
- 목표: 포지셔닝 연습 (킬 수 X)

게임 중:
□ 매 10초마다 "지금 내 포지션 맞나?" 체크
□ 틀렸으면 즉시 수정
□ 맞으면 유지

게임 후:
□ "언제가 가장 좋은 포지션이었나?"
□ "언제가 가장 나쁜 포지션이었나?"
□ "다음엔 뭘 고칠까?"
```

### 주 2회: "맵별 포지셔닝"
```
월요일: 아이작산 포지셔닝 연습 (5게임)
수요일: 리잔 포지셔닝 연습 (5게임)
금요일: 킹스로우 포지셔닝 연습 (5게임)

1주일 = 각 맵 5게임씩 = 깊이 있는 학습
```

### 주 1회: "높은 곳 감각 익히기"
```
목표: 고지점에서 거리감 배우기

연습:
1. 높은 포지션에서만 경기 (저격, 위도우메이커 등)
2. 10게임 연속 고지점 점령
3. "여기서는 안전하다" 감각 체득
```

## 📊 포지셔닝 체크리스트 (매 게임)

### 게임 중 (5분마다)
```
□ 내 포지션이 팀과 함께인가?
□ 탱크가 보이는가?
□ 힐러가 내게 빔을 연결하고 있는가?
□ 뒤에 적이 있을 수도 있다 (경각심)
□ 지금 내 위치가 상황에 맞는가?

만약 "아니오" 답이 하나라도:
→ 즉시 포지션 수정!
```

```

□ 다음엔 뭘 고칠까?

점수 (1-10):
□ 포지셔닝 개선도: __점
```
