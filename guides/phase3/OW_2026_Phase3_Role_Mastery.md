## 🛡️ TANK (탱크) - 팀의 보호자

### 탱크의 진정한 역할

#### 오해하는 것들
```
❌ "탱크 = 킬을 많이 하는 역할"
❌ "탱크 = 혼자 싸우는 역할"
❌ "탱크 = 전선을 계속 밀기"
❌ "탱크 = 체력 많고 강함"

✅ 진실:
"탱크 = 팀을 지키는 역할"
"탱크 = 팀을 위해 피해를 흡수"
"탱크 = 안전한 공간 만들기"
"탱크 = 팀의 신뢰를 받는 역할"
```

### 탱크 2가지 타입

#### Type 1: 보호형 탱크 (라인하르트, 오리사)
```
특징:
- 방패로 팀 보호
- 팀의 진입 신호를 기다림
- "나 버텨, 너희 와"

포지셔닝:
- 항상 팀 최전선
- 뒤를 보지 말기 (팀이 뒤에 있으니까)
- 엄폐물 활용 (방패 + 엄폐물)

행동:
```
시간: 0-10초
"탱크가 먼저 들어간다"
방패를 펼침
→ 딜러들: "이제 가도 된다"
→ 딜러들 진입
→ 팀 공격 시작

역할: 신호를 주는 사람
```

**최고의 순간:**
```
상황: 5v5 정면 전투
우리 탱크: 방패 펼침 (버티는 중)
우리 딜러: 방패 뒤에서 공격
상대팀: 방패 부수려고 필사
→ 10초 지남
→ 우리 궁극기 1개 찬 상태
→ 상대는 궁 못 찬 상태

= 단 10초의 버팀이 게임을 결정!
```

#### Type 2: 기동형 탱크 (윈스턴, D.Va)
```
특징:
- 점프/날기로 빠르게 이동
- 팀과 떨어져서 "분산시키기"
- "나 먼저 들어가, 너희는..."

포지셔닝:
- 적 후방으로 침투
- 적의 주의 분산
- 팀이 정면에서 공격하는 동안

행동:
```
시간: 0초
"탱크가 우회"
윈스턴 점프 → 적 후방
→ 적: "어? 뒤에서 온다?"
→ 저격수: 뒤로 도망 (윈스턴 봐야 하니까)
→ 우리 진입: 저격수 없이 쉬움

역할: 분산시키는 사람
```

**최고의 순간:**
```
상황: 상대팀 저격수가 매우 강함
우리 윈스턴: 저격수한테 점프
상대: "어? 윈스턴이 날 봤나?"
저격수: 우리 쪽에서 도망
→ 우리 진입: 저격수 없으니 쉬움
→ 게임 이김

= 윈스턴 1명이 저격수 2명을 쫓아냄!
```

### 탱크의 3가지 핵심 원칙

#### 원칙 1: "절대 혼자 싸우지 말기"
```
탱크의 실수:
"내가 강하니까 혼자 들어가면 되지"
→ 혼자 5명과 싸움
→ 3초 안에 죽음
→ 팀이 혼자 남음
→ 게임 짐

올바른 방식:
"내가 먼저 가지만, 팀이 뒤에 있다"
→ 딜러들이 따라옴
→ 함께 싸움
→ 게임 이김

체크:
게임 중 "지금 내 뒤에 팀이 보이나?"
보이지 않으면: 너무 앞으로 나간 것
```

#### 원칙 2: "팀의 신호를 기다려라"
```
탱크가 하는 역할:
✅ 진입할 준비 (버티고 있음)
✅ "이제 올까?" 생각 (신호 기다리는 중)
✅ 딜러 신호받음 (예: "가자!")
✅ 함께 진입 (탱크가 먼저, 딜러 따라옴)

탱크의 실수:
❌ 혼자 판단해서 들어가기
❌ "이제 때?" 생각하고 들어가기
❌ 팀 신호 무시하기

결과:
신호 무시 → 혼자 들어감 → 죽음
신호 따르기 → 함께 들어감 → 이김
```

#### 원칙 3: "체력은 팀 자산이다"
```
탱크의 체력 = 팀의 방패

예시:
탱크 체력 50%:
- "아, 나 거의 죽을 것 같으니 물러나자"
→ 이건 팀의 안전을 버린 것

올바른 생각:
- "나 50% 체력 남았으니 팀이 계속 공격 가능"
→ "내가 조금 더 버티자"
→ 팀이 계속 이김

체크:
"내 체력이 떨어졌을 때 팀이 도움이 되나?"
→ 맞다면: 계속 버티기
→ 아니라면: 물러나서 치유받기
```

### 탱크 최고의 순간들

#### 상황 1: "우리 딜러가 곤란할 때"
```
장면:
우리 딜러가 적 저격수한테 쫓김
탱크: "아, 저격수 때문에 딜러가 못 싸운다"

행동:
탱크가 저격수 쪽으로 이동
→ 저격수: "탱크가 온다?" 도망
→ 딜러: "아, 저격수 없네! 이제 공격 가능"

결과:
탱크 1명의 움직임이
딜러 2-3명을 살려냄
```

#### 상황 2: "팀이 몰려있을 때"
```
장면:
우리 팀이 함께 움직이는 중
탱크: "이제 우리가 들어갈 때야"

행동:
탱크가 방패 펼침
→ 팀이 "오, 탱크 신호다" 인식
→ 모두 함께 진입
→ 5v5에서 우리가 먼저 공격

결과:
탱크의 신호 하나가
팀 전체를 움직임
```

## 💣 DAMAGE (딜러) - 적 제거

### 딜러의 진정한 역할

#### 오해하는 것들
```
❌ "딜러 = 킬을 많이 해야 함"
❌ "딜러 = 앞에서 싸워야 함"
❌ "딜러 = 혼자 강하면 됨"
❌ "딜러 = 점수가 높아야 함"

✅ 진실:
"딜러 = 팀의 화력"
"딜러 = 탱크를 믿고 따라가기"
"딜러 = 팀의 일부로서 역할"
"딜러 = 올바른 위치에서 공격"
```

### 딜러 2가지 타입

#### Type 1: 근접 딜러 (트레이서, 겐지)
```
특징:
- 빠른 이동
- 낮은 체력
- 순간 피해
- 우회 공격 가능

포지셀링:
- 탱크의 안전권 내
- 또는 우회로로 적 측면 공격
- 절대 정면에서 혼자 싸우지 말기

행동 패턴:
```
시간: 0초
"탱크 들어가기" → 우리 따라가기
시간: 1초
"탱크 정면 공격" → 딜러는 옆에서 공격
시간: 2초
"한 명 죽음" → 5v4 우위
시간: 3초
"계속 진입" → 게임 이김
```

**최고의 순간:**
```
상황: 트레이서가 적 뒤에서 저격수 처리
적 입장: "어? 뒤에서 누가?"
우리 입장: "아, 트레이서가 저격수 없애주네!"
결과: 저격수 제거 → 우리 진입 쉬움
```

#### Type 2: 원거리 딜러 (위도우메이커, 시에라)
```
특징:
- 거리 유지
- 높은 정확도
- 지속적 피해
- 지형 활용

포지셀링:
- 높은 곳 (고지점)
- 또는 엄폐물 뒤
- 탱크가 정면에서 싸우는 동안 옆에서 지원

행동 패턴:
```
시간: 0초
"탱크 정면 진입" → 저격수는 높은 곳 이동
시간: 1초
"탱크 정면 싸움" → 저격수 지원 공격
시간: 2초
"적 한 명 죽음" → 저격수 기여도 높음
시간: 3초
"계속 진입" → 게임 이김
```

**최고의 순간:**
```
상황: 시에라가 높은 곳에서 저격수 처리
결과: 적 후방 공격 제거 → 우리 진입 쉬움
```

### 딜러의 3가지 핵심 원칙

#### 원칙 1: "탱크를 믿어라"
```
딜러의 불안감:
"탱크가 죽을 것 같으니 내가 뒤로 빠져야 하나?"
→ 뒤로 물러남
→ 탱크 혼자 남음
→ 탱크 죽음
→ 게임 짐

올바른 태도:
"탱크가 버틸 거야, 나는 공격만 하자"
→ 탱크가 버팀 (피해 흡수)
→ 나는 공격 (딜 증가)
→ 적 한 명 죽음
→ 게임 이김

체크:
게임 중 "나 지금 탱크 뒤에 있나?"
→ 맞다면: 계속 공격
→ 아니라면: 탱크 쪽으로 이동
```

#### 원칙 2: "안전한 거리에서 최대 피해"
```
딜러의 실수:
"내가 강하니까 혼자 들어간다"
→ 혼자 맞음
→ 죽음

올바른 방식:
"나는 안전한 거리에서 공격만"
→ 탱크가 버팀
→ 나는 피해 없음
→ 게임 이김

거리의 원칙:
근접 딜러: 탱크로부터 3-5미터
원거리 딜러: 탱크로부터 7-10미터
```

#### 원칙 3: "팀의 목표에 집중"
```
딜러의 실수:
"아, 저 멀리 적이 있네? 저 잡으러 가자"
→ 혼자 갈라짐
→ 팀이 4명 남음
→ 5v4에서 져먹음

올바른 사고:
"팀이 공략하는 곳에 집중"
→ 팀과 함께
→ 숫자 우위
→ 게임 이김

체크:
게임 중 "팀이 뭐 하고 있나?"
→ 팀 따라가기
→ "나 혼자" X
```

### 딜러 최고의 순간들

#### 상황 1: "완벽한 타이밍 공격"
```
장면:
적이 재정렬 중 (새로 스폰됨)
우리 딜러: 그 순간 집중 공격
→ 적 1명 즉사
→ 5v4 우위 생성
```

#### 상황 2: "탱크를 믿는 순간"
```
장면:
탱크가 방패 펼침 (체력 30%)
우리 딜러: "탱크가 버티니까 공격만 하자"
→ 딜 극대화
→ 적 2명 죽음
→ 게임 이김
```

## 🩹 SUPPORT (지원/힐러) - 팀의 생명

### 지원의 진정한 역할

#### 오해하는 것들
```
❌ "지원 = 치유만 하면 됨"
❌ "지원 = 약한 역할"
❌ "지원 = 킬 안 해도 됨"
❌ "지원 = 팀이 지면 내 탓"

✅ 진실:
"지원 = 팀의 생명유지"
"지원 = 가장 중요한 역할"
"지원 = 필요한 순간 강해짐"
"지원 = 팀의 신뢰받는 역할"
```

### 지원 2가지 타입

#### Type 1: 치유 지원 (우양, 바티스트)
```
특징:
- 지속적 치유
- 팀 유지
- 전략적 치유 (누가 먼저)

역할:
```
탱크 체력 100% → 50% → 100% (치유로 회복)
딜러 체력 150% → 50% → 80% (치유 받음)
힐러 체력 200% → 100% → 유지 (자가 치유 또는 힐러가)

= 계속 팀을 살려냄
```

**최고의 순간:**
```
상황: 탱크 체력 10% (거의 죽을 것 같음)
지원: 즉시 치유 강화
→ 탱크 체력 30% → 50% → 70%
→ 탱크 생존
→ 팀이 게임 이김
```

#### Type 2: 보조 지원 (아나, 루시우)
```
특징:
- 버프/디버프
- 치유 + 추가 효과
- 전략적 사용

역할:
```
아나: 수면총 (적 잠재우기) + 치유
루시우: 속도 버프 (팀 빠르게) + 치유

= 치유 + 전략적 효과
```

**최고의 순간:**
```
상황: 적이 궁극기 발동 (치명적)
지원: 아나 수면총 → 적 잠배우기
→ 적 궁극기 취소
→ 팀 생존
→ 게임 이김
```

### 지원의 3가지 핵심 원칙

#### 원칙 1: "팀을 먼저, 나는 나중에"
```
지원의 실수:
"내가 체력 낮으니까 먼저 치유받고"
→ 다른 팀원이 죽음 (치유 못 받음)
→ 팀이 4명 남음
→ 게임 짐

올바른 태도:
"팀 체력이 위험하니까 팀 먼저"
→ 팀이 모두 산다
→ 5명 모두 싸움
→ 게임 이김

우선순위:
1순위: 탱크 (팀의 방패)
2순위: 위험한 딜러
3순위: 자신
```

#### 원칙 2: "팀이 보이는 위치에만"
```
지원의 실수:
"나 혼자 안전한 곳에 숨자"
→ 팀이 치유 못 받음
→ 팀이 죽음
→ 게임 짐

올바른 위치:
"팀이 보이고, 팀이 나를 봐야 함"
→ 치유 연결 가능
→ 팀이 생존
→ 게임 이김

체크:
"지금 내 뒤에 탱크가 보이나?"
→ 보이면: 좋은 위치
→ 안 보이면: 위치 이동
```

#### 원칙 3: "절대 혼자 싸우지 말기"
```
지원의 실수:
"적이 나한테 왔으니까 싸워야지"
→ 혼자 싸움
→ 죽음
→ 팀 치유 끊김
→ 팀 전멸

올바른 반응:
"적이 왔으니까 팀에 외쳐야지"
"팀! 내가 공격받아!"
→ 팀이 도와줌
→ 적 처리
→ 게임 이김

외칠 신호:
- "좌측 공격받음!"
- "뒤에 적!"
- "누가 와줄래?"
```

### 지원 최고의 순간들

#### 상황 1: "절묘한 타이밍의 치유"
```
장면:
탱크 체력 5% (거의 죽을 것)
지원: 그 순간 치유 강화
→ 탱크 생존
→ 게임 이김
```

#### 상황 2: "팀이 도움이 되는 전략"
```
장면:
적이 궁극기 발동할 순간
지원: 추가 효과 (예: 버프, 디버프)
→ 적 궁 효율 떨어짐
→ 팀 생존
→ 게임 이김
```

## 🎯 역할별 최고의 학습 방법

### 탱크 학습 (50게임 기준)
```
목표: 팀의 신뢰를 받는 탱크

게임 1-10: "버팀 연습"
→ 방패/배리어 사용법
→ "얼마나 오래 버틸까" 연습

게임 11-25: "신호 기다리기"
→ "팀이 왔나?" 확인
→ 함께 진입하기

게임 26-35: "팀 보호"
→ "팀이 위험하면?" 돌아가기
→ 팀이 안전한 공간 만들기
```
