# 오버워치 2026 Phase 3 - 고급 팀 전술 & 프로 경기 분석

**기준: 2026년 9월 (현재 메타)**

---

## 🎯 고급 팀 전술 5가지

### 전술 1: "Dive Composition" (다이브 전술)

**정의:**
- 빠른 이동 기반 팀
- 한 번에 여러 곳 공격
- 빠른 킬 수집

**팀 구성:**
```
탱크: 윈스턴 (필수)
딜러: 트레이서, 겐지
힐러: 우양, 루시우
```

**작동 원리:**
```
1단계: 윈스턴 점프 (배리어 펼침)
2단계: 트레이서/겐지 동시 진입
3단계: 힐러 지원 (빔 연결)
4단계: 3v5 → 5v5 후진
결과: 적 1-2명 처리 → 아군 전진
```

**장점:**
- 빠른 게임 진행
- 적응 필요
- 높은 DPS

**단점:**
- 배우기 어려움
- 실패하면 큰 손실
- 조화 필수

**상황:**
- 좋음: 넓은 맵
- 나쁨: 좁은 맵

---

### 전술 2: "Poke Composition" (견제 전술)

**정의:**
- 거리를 유지하며 지속 공격
- 천천히 적 체력 깎기
- 궁극기 모으기

**팀 구성:**
```
탱크: 오리사 (거리 유지)
딜러: 시에라, 위도우메이커
힐러: 바티스트, 아나
```

**작동 원리:**
```
1단계: 거리 유지 (엄폐물 활용)
2단계: 지속적 공격 (피해 축적)
3단계: 적 접근 시 퇴각
4단계: 궁극기 모으기
5단계: 동시 궁극기 사용 → 패주
```

**장점:**
- 안정적
- 조율 쉬움
- 낮은 리스크

**단점:**
- 느린 진행
- 인내력 필요
- 마지막 엄폐물 중요

**상황:**
- 좋음: 경험부족팀
- 나쁨: 프로급팀

---

### 전술 3: "Rush Composition" (돌격 전술)

**정의:**
- 강력한 전진
- 빠른 목표 달성
- 숫자 우위 활용

**팀 구성:**
```
탱크: 라인하르트, 정커퀸
딜러: 정크랫, 겐지
힐러: 브리기테, 우양
```

**작동 원리:**
```
1단계: 모두 함께 전진 (절대 혼자 아님)
2단계: 탱크가 먼저 (피해 흡수)
3단계: 딜러 뒤따르기
4단계: 힐러 지원 (생명유지)
5단계: 한 번에 결정 (승/패)
```

**장점:**
- 명확함
- 심플
- 초급자 OK

**단점:**
- 디지타이징 필요
- 한 명 빠지면 망함
- 거리 유지 팀에 약함

**상황:**
- 좋음: 숫자우위
- 나쁨: 거리 거리팀

---

### 전술 4: "Zone Control" (영역 제어)

**정의:**
- 맵 특정 영역 장악
- 적 진입 차단
- 고지점 확보

**팀 구성:**
```
탱크: 윈스턴, 자리야
딜러: 토르비욘, 메이
힐러: 바티스트, 루시우
```

**작동 원리:**
```
1단계: 고지점/엄폐물 점령
2단계: 적 진입로 차단
3단계: 포탑/함정으로 방어
4단계: 우회로 감시
5단계: 적 고립 → 각개격파
```

**장점:**
- 혼자 강함
- 방어 유리
- 포지션 고정

**단점:**
- 이동성 낮음
- 강한 다이브에 약함
- 칼같은 움직임 필요

**상황:**
- 좋음: 방어 상황
- 나쁨: 공격 상황

---

### 전술 5: "Support Carry" (힐러 중심)

**정의:**
- 힐러를 보호 + 최대한 살리기
- 힐러의 생명유지가 우선
- 치유량 극대화

**팀 구성:**
```
탱크: 윈스턴 (보호)
딜러: 겐지, 트레이서
힐러: 우양 (핵심!)
2번째 힐러: 바티스트
```

**작동 원리:**
```
1단계: 탱크가 힐러 주변에 배리어
2단계: 딜러가 협격팀 순회
3단계: 힐러 절대 혼자 없음
4단계: 힐러 위협 시 즉시 방어
5단계: 힐러 생존 → 팀 생존 → 승리
```

**장점:**
- 치유량 최대
- 팀 협력 극대
- 안정적

**단점:**
- 힐러 스트레스 큼
- 막힐 수 있음
- 높은 신뢰도 필요

**상황:**
- 좋음: 프로급 팀
- 나쁨: 신뢰도 낮은 팀

## 🔄 팀 전술 선택 가이드

### "우리 팀은 뭘 해야 하나?"

**상대 팀 분석:**

1️⃣ **상대가 느린 팀**
→ Dive or Rush
→ 빠르게 끝내기

2️⃣ **상대가 빠른 팀**
→ Zone Control
→ 거리 유지

3️⃣ **상대가 강한 탱크**
→ Poke
→ 거리에서 소진시키기

4️⃣ **상대가 약한 팀**
→ 아무거나 OK
→ 실력으로 이기기

5️⃣ **우리가 강한 팀**
→ Rush
→ 압박하기

6️⃣ **우리가 약한 팀**
→ Poke
→ 시간 벌기

## 🎬 팀 전술 변경 (적응)

### 언제 변경해야 하나?

**신호:**
```
❌ 같은 전술로 2연패
❌ 포지션이 계속 파괴됨
❌ 힐러가 계속 죽음
❌ 탱크가 무기력함
```

**변경 방법:**

```
1단계: 게임 후 팀 채팅
2단계: "다음 라운드 다른 전술"
3단계: 명확한 신호 (음성/채팅)
4단계: 모두 동의하고 실행
5단계: 1게임 평가 후 재결정
```

**예시:**
```
현재: Poke (거리 유지)
→ 계속 실패 (거리 못 유지)
변경: Rush (강하게 밀기)
결과: 1게임 성공!
```

## 📊 프로 경기 분석 방법

### 프로 경기 보는 법 (초급자용)

#### 단계 1: 팀 구성 분석 (0-1분)
```
Q1: 어떤 조합인가?
- Dive? Rush? Poke? Zone?

Q2: 각 팀 강점은?
- 탱크 강함? 딜러 강함?

Q3: 상대의 약점은?
- 거리 약함? 근접 약함?
```

**학습:**
```
프로팀이 선택한 조합
= 현재 메타에서 최고 조합
이걸 배우기
```

---

#### 단계 2: 초반 (1-5분)

**관찰 포인트:**
```
1. 진입로 선택
   - 어디로 나갔나?
   - 왜 그곳인가?

2. 위치 선택
   - 탱크는 어디?
   - 힐러는 어디?

3. 첫 목표
   - 뭘 먼저 했나?
   - 왜?
```

**배우기:**
```
"아, 이 상황에는 이렇게 하는구나"
일반화하기 (우리 팀에 적용)
```

---

#### 단계 3: 중반 (5-15분)

**분석:**
```
1. 팀 우위 시기
   - 언제 이겼나?
   - 뭐가 잘됐나?

2. 팀 위기 시기
   - 언제 위기?
   - 어떻게 극복?

3. 궁극기 사용
   - 타이밍은?
   - 효율은?
```

**배우기:**
```
승패 결정 순간 = 최고 학습 기회
그 순간 뭐가 일어났는지 분석
```

---

#### 단계 4: 후반/결과 (15분+)

**평가:**
```
1. 승리 팀이 뭐 잘했나?
2. 패배 팀이 뭐 못했나?
3. 우리 팀에 적용 가능한가?
```

**액션:**
```
"이것을 우리 팀이 해보자!"
→ 다음 게임 시도
→ 1-2게임 평가
```

## 🎓 프로 경기에서 배우는 5가지

### 1. 포지셀링
```
프로: 매우 정확한 위치
이유: 안전성 + 공격력
배우기: 위치 그대로 따라하기
```

### 2. 타이밍
```
프로: 정확한 공격 타이밍
이유: 궁극기 + 숫자 우위
배우기: 시간 기록해서 반복
```

### 3. 카운터픽
```
프로: 정확한 픽 읽기
이유: 메타 이해 + 경험
배우기: "이 팀에는 이 픽" 외우기
```

### 4. 팀 게임
```
프로: 완벽한 조화
이유: 훈련 + 신뢰
배우기: 소통 + 신호 연습
```

### 5. 심리
```
프로: 침착함 유지
이유: 경험 + 훈련
배우기: 불안 때 숨 쉬기
```

## 🎮 우리 팀이 프로처럼 플레이하기

### Week 1-2: 기초 패턴 익히기
```
1게임 = 1가지 배우기
2게임 = 그것 반복
3게임 = 자동화됨
```

**예시:**
```
"이번 주는 Rush 전술만"
- 월: Rush 공부
- 화-금: Rush 연습 (5게임)
- 토일: Rush 마스터
```

### Week 3-4: 상황 판단 연습
```
"상대 팀 보고 즉시 전술 결정"
시간 제한: 10초
예연: 10회 반복
```

### Week 5-6: 팀 협력
```
"음성 챗으로 신호 개선"
목표: 말 없이 움직임으로 소통
훈련: 신호 4개만 쓰기
```

## 💡 실전 상황별 의사결정

### 상황 1: 숫자 우위 (5v3)
**의사결정:**
```
선택: "우리가 이김!"
행동: 강하게 나가기
타이밍: 즉시 진격
주의: 오버플레이 금지
```

### 상황 2: 숫자 열세 (3v5)
**의사결정:**
```
선택: "도망친다"
행동: 안전한 곳으로
타이밍: 즉시
주의: 절대 싸우기 금지
```

### 상황 3: 숫자 동등 (5v5)
**의사결정:**
```
선택: "상황 봐가며"
행동: 포지션 우위 찾기
타이밍: 신호 기다리기
주의: 팀 신호 따르기
```

### 상황 4: 탱크 먼저 죽음
**의사결정:**
```
선택: "다시 그룹 만들기"
행동: 안전한 곳 집합
타이밍: 즉시
주의: 절대 추격 금지
```

### 상황 5: 힐러가 죽음
**의사결정:**
```
선택: "최대한 보호"
행동: 1초 내 리스폰 힐러 보호
타이밍: 즉시
주의: 새 힐러 누가 와도 보호
```

## 🏆 게임 승률 올리는 5가지 비결

### 1. 일관성 (Consistency)
```
같은 캐릭터 계속 하기
- 처음 50게임: 1개 캐릭터만
- 50-100게임: 역할별 2개
- 100+게임: 자유

이유: 숙련도 극대화
```

### 2. 소통 (Communication)
```
팀에게 계속 말하기:
- "좌측 조심!"
- "궁극기 1분"
- "함께 가자"
- "누가 누구 봤나?"

이유: 팀 조율
```

### 3. 위치 (Positioning)
```
올바른 위치에 있기:
- 탱크: 가장 앞
- 딜러: 탱크 뒤
- 힐러: 딜러 뒤

이유: 생존율 극대
```

### 4. 집중 (Focus)
```
한 목표에 집중:
- "우측 공략!"
- 모두 우측으로
- 하나씩 처리
- 우측 정복

이유: 전력 집중
```

### 5. 침착 (Calmness)
```
불안할 때:
- 깊게 숨 쉬기
- 팀 신호 따르기
- 지난 거 잊기
- 지금만 집중

이유: 실력 100% 발휘
```

## 📈 게임 기록 추적 (자신의 발전)

### 추적할 항목

**매 게임 후 기록:**
```
1. 게임 시간
2. 선택 캐릭터
3. 결과 (승/패)
4. 개인 평가 (1-10점)
5. 배운 점 (1줄)
6. 다음 개선 (1줄)
```

**주간 분석:**
```
월요일: 5게임
화요일: 5게임
...
일요일: 분석 & 계획
```

**발전 추적:**
```
1주차 승률: 40%
2주차 승률: 45%
3주차 승률: 50%

= 실력 향상 증명!
```
