**기준: 2026년 9월 (현재 메타)**

## 🎯 카운터픽이란?

### 정의
```
카운터픽 = "상대를 이길 수 있는 캐릭터"

예시:
상대가 윈스턴?
→ 윈스턴을 이길 수 있는 캐릭터는?
→ 거리를 유지하는 캐릭터들
→ 예: 시에라, 위도우메이커, 아나

= 시에라가 윈스턴의 "카운터"
```

### 카운터의 깊이
```
레벨 1: "아, 이 캐릭터가 좋겠다"
레벨 2: "왜 좋을까? 이유를 알아"
레벨 3: "어떻게 플레이해야 할까?"
레벨 4: "모든 상황에 대비했나?"

우리가 목표: 레벨 3-4
```

## 🛡️ TANK vs TANK (탱크 vs 탱크)

### 윈스턴 (다이브 탱크)
```
강점: 배리어, 빠른 점프, 점프 공격

카운터:
1️⃣ 가장 나쁜 상대: 위도우메이커 (원거리 저격)
   이유: 윈스턴 점프 중 맞음 → 즉사
   
2️⃣ 매우 나쁜 상대: 시에라 (원거리 정확)
   이유: 배리어 뚫림 (투사체가 관통)

3️⃣ 나쁜 상대: 아나 (원거리 수면총)
   이유: 점프 중 수면총 맞음 → 무방비

약한 상대:
✅ 제트팩 캣 (가까워서 회피 가능)
✅ 루시우 (느려서 점프로 도망 가능)
```

### 라인하르트 (방패 탱크)
```
강점: 큰 방패, 근접 공격력, 궁극기

카운터:
1️⃣ 가장 나쁜 상대: 정커랫 (광역 폭발)
   이유: 방패 뒤의 광역 범위 맞음
   
2️⃣ 매우 나쁜 상대: 윈스턴 (배리어 무시)
   이유: 윈스턴 배리어가 라인하르트 방패보다 큼

3️⃣ 나쁜 상대: 트레이서 (근거리 다단 공격)
   이유: 방패 뚫고 근접 피해

약한 상대:
✅ 오리사 (둘 다 느림, 기술로 결정)
✅ D.Va (둘 다 근접, 기술 경합)
```

### 오리사 (거리 탱크)
```
강점: 거리 유지, Fortify (방어 강화), 광선

카운터:
1️⃣ 가장 나쁜 상대: 라인하르트 (근접 치명)
   이유: 라인하르트가 너무 가까워지면 무방비
   
2️⃣ 매우 나쁜 상대: 윈스턴 (점프로 회피)
   이유: 오리사는 느리고 윈스턴은 빠름

3️⃣ 나쁜 상대: 메이 (얼림 기술)
   이유: 메이 얼림에 Fortify 무용지물

약한 상대:
✅ 시에라 (거리는 비슷한데 정확도 경합)
✅ 위도우메이커 (둘 다 거리, 저격이 나음)
```

## 💣 DAMAGE vs DAMAGE (딜러 vs 딜러)

### 시에라 (원거리 딜러)
```
강점: 높은 정확도, 거리 우위, 빠른 투사체

카운터:
1️⃣ 가장 나쁜 상대: 트레이서 (근접 기습)
   이유: 트레이서가 가까우면 시에라 방어 불가
   
2️⃣ 매우 나쁜 상대: 겐지 (반사 기능)
   이유: 시에라 공격을 겐지가 반사

3️⃣ 나쁜 상대: 위도우메이커 (저격 대결)
   이유: 같은 거리, 기술 경합

약한 상대:
✅ 정커랫 (광역에 약함)
✅ 프레야 (느려서 피하기 쉬움)
```

### 트레이서 (근접 딜러)
```
강점: 빠른 이동, 순간 피해, 회피 기능

카운터:
1️⃣ 가장 나쁜 상대: McCree (빠른 사격)
   이유: McCree의 정확도가 트레이서 빠르기를 따라잡음
   
2️⃣ 매우 나쁜 상대: 아나 (수면총)
   이유: 수면총 맞으면 끝
   (기술 레벨에 따라 다름)

3️⃣ 나쁜 상대: 브리기테 (근접 방어)
   이유: 브리기테 보호막이 트레이서 공격 막음

약한 상대:
✅ 정커랫 (광역, 위치 추적 쉬움)
✅ 루시우 (느려서 잡기 쉬움)
```

### 위도우메이커 (저격 딜러)
```
강점: 높은 정확도, 한 발 치명, 거리 우위

카운터:
1️⃣ 가장 나쁜 상대: 윈스턴 (배리어 + 근접)
   이유: 윈스턴이 가까워지면 일방적 패배
   
2️⃣ 매우 나쁜 상대: 트레이서 (근접 기습)
   이유: 위도우메이커는 근접 방어 약함

3️⃣ 나쁜 상대: 시에라 (저격 대결)
   이유: 같은 거리, 기술 경합

약한 상대:
✅ D.Va (방어막 + 근접)
✅ 겐지 (회피 능력)
```

### 겐지 (민첩 딜러)
```
강점: 빠른 이동, 반사, 회피

카운터:
1️⃣ 가장 나쁜 상대: 위도우메이커 (저격)
   이유: 겐지 회피가 위도우메이커 반응 따라잡기 어려움
   (기술 큰 차이 필요)

2️⃣ 매우 나쁜 상대: 트레이서 (근접 능력)
   이유: 둘 다 근접인데 트레이서가 빠름

3️⃣ 나쁜 상대: 브리기테 (근접 방어)
   이유: 브리기테 보호막이 겐지 공격 막음

약한 상대:
✅ 루시우 (느려서 잡기 쉬움)
✅ 정커랫 (광역, 위치 추적)
```

### 정커랫 (광역 딜러)
```
강점: 광역 피해, 방벽 무시, 강한 폭발

카운터:
1️⃣ 가장 나쁜 상대: 시에라 (정확도)
   이유: 시에라가 거리에서 정확도로 이김
   
2️⃣ 매우 나쁜 상대: 위도우메이커 (저격)
   이유: 위도우메이커 한 발 치명

3️⃣ 나쁜 상대: 트레이서 (근접 회피)
   이유: 트레이서가 정커랫 광역 회피 가능

약한 상대:
✅ 라인하르트 (광역이 방패 뒤에 먹힘)
✅ 오리사 (거리 유지로 광역 피함)
```

## 🩹 SUPPORT vs SUPPORT (지원 vs 지원)

### 우양 (치유 지원)
```
강점: 높은 치유량, 지속적 힐, 생존력

카운터:
1️⃣ 가장 나쁜 상대: 위도우메이커 (저격)
   이유: 우양은 방어 수단 부족
   
2️⃣ 매우 나쁜 상대: 트레이서 (근접 기습)
   이유: 우양 방어 어려움

3️⃣ 나쁜 상대: 아나 (수면총)
   이유: 수면총 맞으면 팀 치유 끊김

약한 상대:
✅ 제트팩 캣 (둘 다 비슷한 레벨)
✅ 바티스트 (치유 대전)
```

### 아나 (지원 + 전략)
```
강점: 수면총, 원거리 치유, 버프

카운터:
1️⃣ 가장 나쁜 상대: 트레이서 (근접 회피)
   이유: 트레이서가 가까우면 아나 방어 불가
   
2️⃣ 매우 나쁜 상대: 윈스턴 (배리어)
   이유: 윈스턴 배리어가 아나 수면총 막음

3️⃣ 나쁜 상대: 겐지 (반사)
   이유: 아나 슈팅을 겐지 반사

약한 상대:
✅ 루시우 (거리 경합)
✅ 우양 (치유 경합)
```

### 바티스트 (치유 + 방어)
```
강점: 불사장, 광선 치유, 높은 피해

카운터:
1️⃣ 가장 나쁜 상대: 트레이서 (근접 기습)
   이유: 트레이서 빠르면 불사장 반응 못함
   
2️⃣ 매우 나쁜 상대: 위도우메이커 (저격)
   이유: 바티스트는 거리 유지 약함

3️⃣ 나쁜 상대: 정커랫 (광역)
   이유: 광역이 불사장 효과 범위 벗어남

약한 상대:
✅ 아나 (기술 경합)
✅ 우양 (치유 경합)
```

### 루시우 (버프/속도 지원)
```
강점: 속도 버프, 광역 치유, 음파

카운터:
1️⃣ 가장 나쁜 상대: 위도우메이커 (저격)
   이유: 루시우는 거리 유지 약함
   
2️⃣ 매우 나쁜 상대: 겐지 (근접)
   이유: 겐지 근접이 루시우 방어 뚫음

3️⃣ 나쁜 상대: 트레이서 (근접)
   이유: 트레이서 빠르면 루시우 방어 어려움

약한 상대:
✅ 정커랫 (광역이 여러 명 맞춤)
✅ 아나 (기술 경합)
```

## 📊 게임 중 카운터픽 활용법

### 상황 1: 게임 시작 (픽 단계)
```
상대팀 구성 확인:
"상대가 윈스턴 + 트레이서 + 우양"
→ "그럼 우리는?"

우리 팀 구성:
탱크: 오리사 (윈스턴 거리 유지)
딜러: 시에라 + 위도우메이커 (거리 우위)
지원: 아나 (트레이서 수면총)

= 완벽한 카운터!
```

### 상황 2: 게임 중 (상황 변화)
```
초반: 상대가 라인하르트 → 우리 정커랫 OK
중반: 라인하르트가 자꾸 죽어서 윈스턴으로 변경
→ "어? 내 정커랫 효율 떨어졌다"
→ 우리도 시에라로 변경 (윈스턴 카운터)

= 실시간 적응
```

### 상황 3: 팀과 협의
```
내: "상대 트레이서 계속 문제인데, 누가 아나 할래?"
팀원: "내가 아나로 바꿀게"
→ 팀원이 트레이서 수면총 담당
→ 팀 문제 해결

= 팀 커뮤니케이션
```

## 🎯 카운터 활용 팁

### 팁 1: "반드시 이기는 게 아니다"
```
카운터픽의 오해:
"윈스턴의 카운터는 시에라야"
→ 그래서 시에라 선택
→ 하지만 시에라 기술이 떨어짐
→ 윈스턴이 이김

진실:
카운터픽 = "약간의 우위"
→ 기술도 중요
→ 플레이도 중요
→ "우리가 기술이 낫고, 카운터도 맞으면" 이김
```

### 팁 2: "상황에 따라 다르다"
```
윈스턴이 항상 약한가?
→ 아니다!

상황 1: 개방적인 맵 + 거리 유지 힘든 조건
→ 윈스턴 강함 (점프로 가까워질 수 있음)

상황 2: 좁은 맵 + 높은 건물 많음
→ 윈스턴 약함 (거리 유지하기 쉬움)

= 맵에 따라 카운터가 달라짐
```

### 팁 3: "팀 구성이 더 중요"
```
시에라가 윈스턴 카운터지만:
우리 팀: 시에라만 있고 나머지 약함
상대팀: 윈스턴 + 강한 팀 조합

결과: 우리가 짐
= 시에라 카운터도 팀이 약하면 의미 없음
```

## 📈 카운터 학습 프로세스

### Week 1: "학습"
```
각 캐릭터마다:
□ "이 캐릭터를 이길 수 있는 캐릭터는?"
□ "왜 이길까?"
□ "어떻게 싸워야 할까?"

예: "윈스턴을 이기려면?"
→ "거리를 유지해야 한다"
→ "그래서 저격수가 좋다"
→ "시에라가 최고, 위도우메이커도 좋다"
```

### Week 2-3: "연습"
```
각 매치업마다 게임:
□ 시에라 vs 윈스턴 (5게임)
□ 위도우메이커 vs 윈스턴 (5게임)
□ 윈스턴 vs 라인하르트 (5게임)
...

결과: "아, 이래서 카운터구나" 체감
```

### Week 4: "실전"
```
게임 중:
상대팀 픽 → 즉시 카운터 생각
→ "아, 저건 뭐가 좋겠다"
→ "내가 할 수 있나?" 판단
→ 선택

결과: 자연스러운 카운터픽
```

## 🎮 카운터픽 체크리스트

### 매 게임 시작
```
□ 상대팀 구성 파악했나?
```

```
□ 내 픽이 좋았나?
□ 왜 이겼나/졌나? (카운터 영향?)
□ 다음에 뭘 배웠나?
□ 같은 상황 다음에는? (다른 픽?)
```
