## 🎯 카운터픽이란?

### 정의
```
카운터픽 = "상대를 이길 수 있는 캐릭터"

예시:
상대가 Winston?
→ Winston을 이길 수 있는 캐릭터는?
→ 거리를 유지하는 캐릭터들
→ 예: Sierra, Widowmaker, Ana

= Sierra가 Winston의 "카운터"
```

### 카운터의 깊이
```
레벨 1: "아, 이 캐릭터가 좋겠다"
레벨 2: "왜 좋을까? 이유를 알아"
레벨 3: "어떻게 플레이해야 할까?"
레벨 4: "모든 상황에 대비했나?"

우리가 목표: 레벨 3-4
```

## 📊 게임 중 카운터픽 활용법

### 상황 1: 게임 시작 (픽 단계)
```
상대팀 구성 확인:
"상대가 Winston + Tracer + Wuyang"
→ "그럼 우리는?"

우리 팀 구성:
탱크: Orisa (Winston 거리 유지)
딜러: Sierra + Widowmaker (거리 우위)
지원: Ana (Tracer 수면총)

= 완벽한 카운터!
```

### 상황 2: 게임 중 (상황 변화)
```
초반: 상대가 Reinhardt → 우리 Junkrat OK
중반: Reinhardt가 자꾸 죽어서 Winston으로 변경
→ "어? 내 Junkrat 효율 떨어졌다"
→ 우리도 Sierra로 변경 (Winston 카운터)

= 실시간 적응
```

### 상황 3: 팀과 협의
```
내: "상대 Tracer 계속 문제인데, 누가 Ana 할래?"
팀원: "내가 Ana로 바꿀게"
→ 팀원이 Tracer 수면총 담당
→ 팀 문제 해결

= 팀 커뮤니케이션
```

## 🎯 카운터 활용 팁

### 팁 1: "반드시 이기는 게 아니다"
```
카운터픽의 오해:
"Winston의 카운터는 Sierra야"
→ 그래서 Sierra 선택
→ 하지만 Sierra 기술이 떨어짐
→ Winston이 이김

진실:
카운터픽 = "약간의 우위"
→ 기술도 중요
→ 플레이도 중요
→ "우리가 기술이 낫고, 카운터도 맞으면" 이김
```

### 팁 2: "상황에 따라 다르다"
```
Winston이 항상 약한가?
→ 아니다!

상황 1: 개방적인 맵 + 거리 유지 힘든 조건
→ Winston 강함 (점프로 가까워질 수 있음)

상황 2: 좁은 맵 + 높은 건물 많음
→ Winston 약함 (거리 유지하기 쉬움)

= 맵에 따라 카운터가 달라짐
```

### 팁 3: "팀 구성이 더 중요"
```
Sierra가 Winston 카운터지만:
우리 팀: Sierra만 있고 나머지 약함
상대팀: Winston + 강한 팀 조합

결과: 우리가 짐
= Sierra 카운터도 팀이 약하면 의미 없음
```

## 📈 카운터 학습 프로세스

### Week 1: "학습"
```
각 캐릭터마다:
□ "이 캐릭터를 이길 수 있는 캐릭터는?"
□ "왜 이길까?"
□ "어떻게 싸워야 할까?"

예: "Winston을 이기려면?"
→ "거리를 유지해야 한다"
→ "그래서 저격수가 좋다"
→ "Sierra가 최고, Widowmaker도 좋다"
```

### Week 2-3: "연습"
```
각 매치업마다 게임:
□ Sierra vs Winston (5게임)
□ Widowmaker vs Winston (5게임)
□ Winston vs Reinhardt (5게임)
...

결과: "아, 이래서 카운터구나" 체감
```

### Week 4: "실전"
```
게임 중:
상대팀 픽 → 즉시 카운터 생각
→ "아, 저건 뭐가 좋겠다"
→ "내가 할 수 있나?" 판단
→ 선택

결과: 자연스러운 카운터픽
```

## 🎮 카운터픽 체크리스트

### 매 게임 시작
```
□ 상대팀 구성 파악했나?
□ "뭐가 좋을까?" 생각해봤나?
□ "내가 그 캐릭터 할 수 있나?" 확인?
□ 팀에 제안했나?
□ 최종 선택은? (카운터 맞춤? 아니면 협력?)
```

### 매 게임 후
```
□ 내 픽이 좋았나?
□ 왜 이겼나/졌나? (카운터 영향?)
□ 다음에 뭘 배웠나?
□ 같은 상황 다음에는? (다른 픽?)
```
