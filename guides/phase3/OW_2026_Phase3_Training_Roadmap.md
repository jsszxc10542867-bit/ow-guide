## 🎓 3개월 안정 계획 (Silver → Platinum)

### 월간 목표
```
1개월: Bronze/Silver → Gold (2500-2600)
2개월: Gold → Platinum (2800-3000)

총 게임: 624게임
승률 목표: 55% (340게임 승리)
```

### 월간 커리큘럼

#### 1개월: "기초 완성"
```
주제: 한 캐릭터 마스터 + 기본 전술

1주: 캐릭터 선택 (역할 1개 고정)
└─ 예: "지원팀 선택" → 우양 마스터

2주: 캐릭터 심화 (50게임)
└─ 우양의 모든 기술 이해
└─ 상황별 위치 선택

3주: 팀 전술 (3가지 시도)
└─ 우양이 강한 전술 찾기
└─ 팀과 조화

4주: 맵별 숙달
└─ 우양이 강한 맵 집중
└─ 약한 맵 회피

결과: Gold 도달
승률: 55%
게임: 84게임
```

#### 2개월: "다양성 확보"
```
주제: 역할별 2개 캐릭터 + 전술 다양화

1주: 2번째 캐릭터 선택 (같은 역할)
└─ 예: 우양 + 바티스트 (둘 다 지원)

2주: 2개 캐릭터 병행 (각 25게임)
└─ 우양: 팀 치유 전문
└─ 바티스트: 방어 + 조기 치유 전문

3주: 전술 확장 (모든 전술 시도)
└─ 각 전술에서 제 역할 파악
└─ "이 전술에서는 내가 뭐하지?"

4주: 카운터 픽 (다른 역할 시도)
└─ 딜러 역할도 조금 해보기
└─ "아, 이래서 딜러가 힘들구나" 이해

결과: 2800 도달
승률: 55-58%
게임: 52게임/월
```

#### 3개월: "상위권 진입"
```
주제: 3개 캐릭터 + 팀 신뢰도 + 멘탈

1주: 최적 캐릭터 3명 선택
└─ 상황별로 다른 캐릭터
└─ 팀이 부르면 맞춰줄 수 있도록

2주: 팀 신뢰도 구축
└─ 같은 팀원과 계속 플레이
└─ "이 친구는 이렇게 하겠지" 예상 가능

3주: 멘탈 안정화
└─ Phase 3 멘탈 마스터리 실행
└─ "패배도 배움" 수용

4주: 상위권 진입 + 안정화
└─ 3000 근처 게임
└─ 승률 유지 (60% 목표)

결과: Platinum 달성 + 안정화
승률: 55-60%
게임: 52게임/월
```
